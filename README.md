🛠️ Package Component Overview

•    src/lhguard/validator.py: Manages the isolation sandbox. It writes incoming LLM code strings to temporary scratchpads, invokes lake env lean to natively resolve Mathlib dependencies, and enforces strict execution timeouts.
• 🤖 src/lhguard/client.py: The agentic correction engine. It parses raw compiler errors to isolate the exact symbol ⊢ (unsolved goal state) alongside line/column coordinates. It feeds this parsed tactical state directly back to the LLM, transforming generic stack traces into targeted, actionable debug directives.
• 👁️ src/lhguard/watcher.py: A lightweight background daemon. It monitors your local markdown folders, automatically isolating and checking embedded lean code blocks the moment you save your documents.
• 📜 src/lhguard/utils/logger.py: A dual-logging pipeline. It prints clean, scannable milestones to the developer console while dumping deep compiler tracebacks and loop telemetry to your local disk.
